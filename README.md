# Quicker - תבניות שומה ל-Claude

תוסף ל-Claude שהופך דוח שמאות בוורד לתבנית מסמך של Quicker - בלי לגעת בעיצוב.

מעלים לשיחה דוח שכבר הפקתם (או תבנית ריקה של המשרד), ו-Claude מחזיר קובץ וורד באותו עיצוב בדיוק,
שבו כל נתון שמשתנה מתיק לתיק הוחלף במשתנה מטופס השומה שלכם ב-Quicker. מעלים את הקובץ ל-Quicker,
ומעכשיו כל דוח יוצא מהמערכת כשהוא כבר מלא.

---

## מה התוסף עושה

- **שומר על העיצוב.** כותרות, טבלאות, תיבות טקסט, מספור, כותרת עליונה ותחתונה - הכול נשאר כמו בקובץ
  שלכם. התוסף רק מכניס משתנים במקומות הנכונים.
- **מוצא לבד איפה צריך משתנים.** ערכים כמו גוש, חלקה, שמות, תעודות זהות, תאריכים, סכומים ושטחים,
  וגם שדות ריקים אחרי תווית ("גוש: ____") או תאים ריקים בטבלה.
- **משתמש בשדות האמיתיים של הטופס שלכם.** המשתנים נלקחים בכל פעם ישירות מ-Quicker, מטופס המערכת או
  מטופס מותאם של המשרד. אין משתנים מומצאים, וכל ערך שאין לו שדה מתאים מסומן לכם בדוח.
- **מוסיף תנאים.** פסקה, פרק שלם או שורה בטבלה שמופיעים רק לפעמים - למשל רק בשומה מורחבת, רק
  כשיש חריגות בנייה, או רק לבנק מסוים.
- **מוסיף לולאות.** רשימות שחוזרות על עצמן - לווים, בעלים, היתרים, תכניות, הצמדות, משכנתאות - יוצגו
  כשורה או פסקה לכל פריט, כמה שיש בתיק.
- **תמונות.** תמונות הנכס, תשריטים וגלריות בגודל ובפריסה שתבחרו, כולל חתימה ולוגו של המשרד.
  תמונות לדוגמה של לקוחות מוסרות מהקובץ.
- **בודק לפני שהוא מוסר.** כל תבנית עוברת בדיקת תקינות וייצור ניסיון של דוחות עם נתונים לדוגמה, כדי
  שלא תגלו תקלה רק כשלקוח מקבל דוח.
- **מסביר מה עשה.** יחד עם התבנית מקבלים דוח מיפוי בעברית: איזה ערך מופה לאיזה שדה, אילו תנאים נוספו,
  ומה מחכה להחלטה שלכם.
- **בודק תבניות קיימות.** אפשר להעלות תבנית שכבר עובדת ב-Quicker ולבקש לבדוק אותה. התוסף מוצא
  משתנים שגויים, תנאים שלא יעבדו ושדות שלא קיימים בטופס.

## מה צריך

- חשבון Quicker פעיל.
- חשבון Claude - באתר claude.ai או באפליקציה למחשב.
- הרצת קוד ויצירת קבצים מופעלות בחשבון Claude. בחשבון ארגוני זה תלוי בהגדרות של מנהל החשבון.

---

## התקנה

### חשבון אישי

1. ב-Claude נכנסים ל-**Customize** ← **Plugins**.
2. לוחצים **Add** ← **Add marketplace**, ומזינים:
   ```
   quicker-il/quicker-claude-plugins
   ```
3. ברשימת התוספים בוחרים **Quicker Appraisal Templates** ולוחצים **Install**.
4. פותחים את התוסף, עוברים ללשונית **Connectors** ולוחצים **Connect** ליד Quicker.
   נפתח חלון התחברות - מתחברים עם המשתמש שלכם ב-Quicker.
   (אם מופיע **Add** במקום **Connect**, לוחצים עליו קודם.)

זהו. התוסף זמין בצ'אט, ב-Cowork וב-Claude Code.

### משרד עם חשבון Claude ארגוני (Team / Enterprise)

מנהל החשבון (Owner):

1. **Organization settings** ← **Connectors** - מוסיף את Quicker כקונקטור מותאם, בכתובת
   ```
   https://app.quicker.co.il/api/mcp
   ```
2. בוחר איך העובדים יקבלו את התוסף:
   - **כל עובד מתקין לבד (מומלץ - עדכונים מגיעים אוטומטית):** ב-**Organization settings** ←
     **Plugins & skills** ← **Policy** מוודאים ש-**User-created skills** פעיל, וכל עובד מתקין לפי
     ההוראות לחשבון אישי.
   - **התקנה מרוכזת לכולם:** מורידים את קובץ ה-zip של הגרסה האחרונה מעמוד
     [Releases](https://github.com/quicker-il/quicker-claude-plugins/releases), ואז **Organization settings** ←
     **Plugins & skills** ← **Add** ← **Upload a plugin**, ובוחרים **Installed by default**.
     בדרך הזו עדכונים לא מגיעים לבד - בכל גרסה חדשה מעלים את הקובץ החדש (**Upload new version** בתפריט
     של התוסף).

כל עובד מתחבר ל-Quicker עם המשתמש שלו, מלשונית **Connectors** של התוסף.

### Claude Code

```bash
claude plugin marketplace add quicker-il/quicker-claude-plugins
claude plugin install quicker-appraisal@quicker
```

## עדכונים

גרסאות חדשות מגיעות מאותו מקום שממנו התקנתם.

- **חשבון אישי:** ב-**Customize** ← **Plugins** פותחים את ה-marketplace ומפעילים **Sync automatically**,
  ואז כל עדכון מגיע לבד. בלי זה - לוחצים מדי פעם **Check for updates**.
- **חשבון ארגוני עם התקנה מרוכזת:** מנהל החשבון מעלה את קובץ הגרסה החדשה מעמוד
  [Releases](https://github.com/quicker-il/quicker-claude-plugins/releases). הגרסה המותקנת מופיעה בעמוד התוסף
  בהגדרות הארגון, והשינויים בכל גרסה מופיעים ב-[CHANGELOG](plugins/quicker-appraisal/CHANGELOG.md).

## איך משתמשים

מצרפים לשיחה את קובץ הוורד וכותבים מה רוצים. למשל:

> תהפוך את הדוח הזה לתבנית ל-Quicker לפי טופס "שומת מקרקעין".

> זו תבנית ריקה של הדוח לבנק. תמקם בה משתנים מהטופס של המשרד, כולל תנאים איפה שצריך.

> תבדוק לי את התבנית הזו - היא מפיקה שדות ריקים.

אם לא ציינתם טופס, Claude ישאל לאיזה טופס שומה התבנית מיועדת.

**מה מקבלים:**

- `<שם הקובץ>_template.docx` - התבנית, מוכנה להעלאה.
- דוח מיפוי - מה נעשה, ומה מחכה להחלטה שלכם.

**העלאה ל-Quicker:** הגדרות ← טפסי שומה מותאמים ← תבניות מסמכים. אפשר גם לפתוח את התבנית בוורד עם
התוסף של Quicker ולהריץ "זיהוי ביטויים".

> לפני שמשתמשים בתבנית לדוחות אמיתיים, כדאי להפיק איתה דוח אחד על תיק קיים ולעבור עליו.

## סימון הוראות בתוך הוורד (לא חובה)

אפשר להגיד ל-Claude בדיוק מה רוצים, ישר בתוך המסמך. כותבים הוראה בסוגריים מרובעים כפולים, במקום
שבו היא חלה:

| כותבים | מה קורה |
|---|---|
| `[[גוש]]`, `[[תאריך הביקור]]`, `[[שווי שוק]]` | כאן ייכנס הערך של השדה |
| `[[אם: שומה מורחבת]]` ... `[[סוף]]` | הקטע שביניהם יוצג רק כשהתנאי מתקיים |
| `[[אם: ...]]` ... `[[אחרת]]` ... `[[סוף]]` | קטע אחד כשהתנאי מתקיים, אחר כשלא |
| `[[פסקה אם: יש מעלית]]` בתחילת פסקה | כל הפסקה מותנית |
| `[[לכל: בעלים]]` ... `[[סוף]]` | הקטע יחזור לכל פריט ברשימה |
| `[[שורה לכל: היתרים]]` בתוך שורה בטבלה | השורה תשוכפל לכל פריט |
| `[[שורה אם: נכס בבנייה]]` בתוך שורה בטבלה | השורה תוצג רק כשהתנאי מתקיים |
| `[[תמונה: תמונות הבניין, 2 בשורה]]` | תמונה או גלריה |
| `[[קבוע]]` בתחילת פסקה | הפסקה תישאר טקסט קבוע |
| `[[הערה: הפסקה הזו רק לבנק לאומי]]` | הוראה חופשית ל-Claude, לא נכנסת לתבנית |

אפשר גם להשתמש בהערות של וורד (סקירה ← הערה חדשה) עם אותן הוראות בלי הסוגריים, או לסמן בצהוב ערך
לדוגמה כדי לומר "זה נתון שמשתנה". את השדות ואת התנאים כותבים בעברית רגילה, כמו שהם מופיעים בטופס.

## כדאי לדעת

- **מה אין ב-Quicker:** מספר רישיון השמאי, טלפון ודוא"ל של השמאי וחתימה אישית לכל שמאי. אותם כותבים
  בתבנית כטקסט קבוע. התוסף יסמן לכם את המקומות.
- **ערכים בלי שדה מתאים** נשארים כטקסט קבוע ומסומנים בדוח המיפוי כ"חשוב". צריך להחליט אם להשאיר אותם
  קבועים או להוסיף שדה לטופס.
- **שורות ריקות:** במקרים מסוימים (למשל תנאי שמסתיים מיד אחרי טבלה) מנוע ההפקה משאיר שורה ריקה אחת.
  התוסף מציין איפה זה קורה.

## מידע ופרטיות

- הקובץ שאתם מעלים נשאר בסביבת העבודה של Claude.
- התוסף קורא מ-Quicker רק את מבנה טופס השומה (שדות ואפשרויות), בהרשאות של המשתמש שלכם. הוא לא כותב
  ל-Quicker ולא משנה נתונים.
- לבדיקת התבנית, התוסף מתקין בסביבת העבודה של Claude את מנוע התבניות שבו Quicker משתמש (חבילות קוד
  פתוח מ-npm). אם אין לכך גישה, הבדיקה מתבצעת חלקית, ו-Claude אומר זאת במפורש.
